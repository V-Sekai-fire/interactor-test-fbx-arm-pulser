# interactor-test-fbx-arm-pulser

An animated arm model in FBX with reference OBJ geometry at sampled frames, for import tests.

## What it is for

An importer test reads the FBX file, bakes its animation, and compares the result with the compressed OBJ files beside it. `arm-pulser.json` records the title, author, licence and the importer options the test uses.

## Build and run

There is nothing to build; the files are read as they are.
